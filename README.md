# Nusantara Cyber Survivor (Kampung Metropolitan 2077)

Game aksi *top-down arena survival* 2D bertema **Cyberpunk Nusantara** yang dibangun menggunakan **HTML5 Canvas** dan **Vanilla JavaScript** (zero-dependency).

## Fitur Utama
- **3 Jagoan Lokal Playable**:
  - **Bang Ojol (Cyber Rider)**: Lincah dengan jurus *Konvoi Paket Kilat*.
  - **Jawara Silat (Crit Pendekar)**: Peluang *Critical Hit* tinggi dengan jurus *Cakra Harimau Putih*.
  - **Pak Hansip (Mecha Ronda)**: Armor tebal dengan meriam ledak area dan perisai *Kentongan Ronda*.
- **Musuh Urban Legend & Boss**: Lawan gerombolan *Pocong Cyber*, *Tuyul Pencuri Receh*, *Kuntilanak Drone*, serta *Boss Buto Ijo Mecha* setiap kelipatan 3 level.
- **Power-Up Kuliner Lokal**: Ambil **Kopi Sachet** (*Overdrive*), **Es Teh Jumbo** (*Heal*), dan **Petasan Banting** (*EMP Blast*) yang muncul acak di jalanan.
- **Arena Jalanan Malam Indonesia**: Latar aspal lengkap dengan trotoar kuning-hitam, *zebra cross*, dan neon *Warteg 24 Jam*.

## Kontrol Permainan
- **W / A / S / D** atau **Arrow Keys**: Bergerak
- **Spasi**: Ngebut (*Dash* + kebal sesaat)
- **E**: Jurus Pamungkas (*Ultimate*)
- **P / ESC**: Pause / Resume
